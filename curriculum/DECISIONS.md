# Решения и гипотезы pilot-1

Статус: владелец поручил реализовать план аудита 29.10.2026. Общая педагогическая логика опирается на обзоры SOURCES.md; первичные ссылки не прошли независимую проверку. Техническая реализация не доказывает эффективность обучения.

| ID | Решение и основание | Альтернатива / проверка пересмотра |
|---|---|---|
| D01 | CLIL+PBL: язык служит созданию сайта; оценивать процесс и объяснение. Обзоры R01/R02, разделы CLIL/PBL и рубрики. Продуктовая адаптация, не доказательство результата этого курса. | Отдельные языковые упражнения; проверить самостоятельное объяснение решения и понимание слов. |
| D02 | About Me: 2 AI-запроса и ручная правка; бонус-хобби без второго запроса. Существующий interaction flow и локальная история решения владельца 04.08, исходная переписка отдельно не предоставлена. | Больше итераций; измерить завершение/скучание/осмысленность правок. |
| D03 | +3 слова и 2 слова банка About Me — пилотная прокси полезного уточнения; не научный минимум. Обзоры Фазы 0 обсуждают языковое плато, не доказывают этот порог. | Содержательное уточнение; учитель отмечает пустые добавления и полезные сокращения. |
| D04 | Один изменённый символ — защита от совершенно неизменённого copy/paste, не оценка качества. | Обязательное обоснование/проверка учителя. Пересмотреть при косметических обходах. |
| D05 | L3 3…6 версий и best/worst — материал для сравнения. R01/R02 предлагают различные минимумы; точные 3/6 — настройка курса. | Две версии или демонстрационный набор. Измерить время/помощь, качество сравнения и стоимость. |
| D06 | L4 1…6 — снятие опор, на основе обсуждения scaffolding в R01/R02. | Обязательные повторы; проверить независимость выбора, не число кликов. |
| D07 | Present Perfect и лимиты текста — языковая задача и ограничения слотов. Heuristic не оценивает всю грамматику. | Неблокирующая проверка; учитывать ложные отказы и уровень группы. |
| D08 | 6×15 слов рефлексии — настройка пилота с риском перегрузки. R03/R04 поддерживают рефлексию, но не точную норму. | Меньше вопросов/устный ответ. Измерить 15-минутный блок и содержательность. |
| D09 | Личный AI-ответ не портить; плохой общий пример подготовлен заранее. Разрешён конфликт прежних документов по рекомендации аудита. | Скрытое ухудшение отвергнуто: искажает опыт и обратную связь. |
| D10 | Шесть пресетов и языковое сравнение — ограниченный выбор для пилота. Нормативного основания числу шесть нет. | Свободная палитра; измерить понятность и различимость результатов. |
| D11 | Приватность: псевдонимы, только стилизованные аватары, черновики с доступом, передача учителем. R03/R04; организационные разрешения уточняются до группы. | Без общего публичного каталога. Экспорт не объявляется автоматическим окончанием всех обязательств по данным. |
| D12 | Оценка: J=(Prompt+Editing)/2; S=.4J+.3Defense+.3Website, все критерии 1…4. Продуктовый выбор одного варианта из R01/R02. | Пересматривать после сравнения оценок преподавателей. Пример 3,4,3,4: J=3.5,S=3.5. |

Каждое изменение: ID, автор/дата, ожидаемая польза, затронутые поля/данные и регрессионный пример. После первого пилота записать факты и решение оставить/изменить/проверить ещё раз. Старый курс не переписывать задним числом в активных профилях.
