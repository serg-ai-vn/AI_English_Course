# AI English Course Platform (`My AI Website`)

Интерактивная образовательная платформа для проектного курса **English + AI Literacy** (дети 10–14 лет, уровень английского A2–B1).

Ученик выступает в роли **Оператора ИИ (AI Operator)**: по шагам создаёт и редактирует промпты на английском языке, критически оценивает черновики текста и сгенерированные изображения, выбирает дизайн-тему и на финальном занятии защищает свой полноценный персональный сайт с анимацией частиц.

---

## Быстрый старт (Локальный запуск)

Требуется установленный **Node.js >= 18** (внешние npm-пакеты для базовой версии не нужны — сервер работает на нативных модулях Node.js).

```bash
# 1. Скопировать шаблон переменных окружения
cp .env.example .env

# 2. Запустить сервер платформы
npm start
# или напрямую:
node platform/server.js
```

После запуска открой в браузере:
- **Вход для ученика и учителя:** `http://localhost:3000/login.html`
  - Тестовый код класса: `DEMO`
  - PIN учителя: `0000`
  - Тестовые ученики (`name` / `PIN`):
    - `Lumi` (`1111`) — предзаполненный демо-профиль (уроки 2–4 закрыты, готов к проверке `Build site` в консоли учителя; можно сбросить кнопкой `Reset ALL progress` в UI)
    - `Ziggy` (`2222`), `Neo` (`3333`), `Khoa` (`4444`), `Nia` (`5555`), `Rex` (`6666`) — чистые профили (`Lesson 2`, пустые поля) для пошагового тестирования гейтинга с нуля
- **Рабочее место ученика:** `http://localhost:3000/workspace.html`
- **Консоль учителя:** `http://localhost:3000/teacher.html`

## Архитектура проекта

Проект состоит из трёх связанных контуров внутри репозитория:

1. **Учебная веб-платформа (`platform/`)**:
   - `platform/server.js` — HTTP-сервер, авторизация по сессиям, управление уроками (Lessons 2–5), API генерации текста/картинок и сборка итогового сайта.
   - `platform/validate.js` — детерминированный движок правил гейтинга (проверка формулы промпта `Role / Context / Task / Format`, структуры `Subject / Style / Framing / Lighting`, длины рефлексии и др.).
   - `platform/config/lesson-2.json .. lesson-5.json` — декларативные схемы заданий, подсказок и словарных банков для каждого урока.
   - `platform/public/` — клиентское приложение ученика (`app.js`, `workspace.html`) и панель управления учителя (`teacher.js`, `teacher.html`).

2. **Движок персонального сайта ученика (корень + `tools/` + `rehearsal/assets/`)**:
   - `index.html`, `styles.css`, `motion.js`, `particles.js`, `flight.js`, `carousel.js` — модульный шаблон сайта ученика с 6 цветовыми пресетами и интерактивными эффектами.
   - `tools/fill-slots.js` — скрипт безопасной подстановки данных ученика (`window.SITE_DATA`) в слоты DOM.
   - `rehearsal/assets/` и `demo-assets/` — графические ассеты и предрассчитанные сетки частиц для демо-учеников.
   - `dist/` — готовые собранные самодостаточные HTML-сайты учеников.

3. **Педагогическая спецификация и инварианты (`curriculum/` + `docs/`)**:
   - `docs/SYSTEM_INVARIANTS.md` — главный паспорт методологии уроков 1–5, правил гейтинга, контракта для OpenAI и матрицы межфайловых зависимостей кода.
   - `curriculum/Lesson_1.md .. Lesson_5.md` и `curriculum/1_course_guide_teacher.md` — канонические планы уроков и методическое руководство курса.

## Работа с ИИ-агентом и очередь задач (`tasks/`)

Вся разработка ведётся итеративно по одной задаче с соблюдением педагогических и архитектурных инвариантов:
- Правила для агента и протокол `Impact Check` описаны в **`AGENTS.md`**.
- Неприкосновенные инварианты уроков и матрица связности кода находятся в **`docs/SYSTEM_INVARIANTS.md`**.
- Текущий статус проекта хранится в **`SESSION.md`**.
- Пошаговые технические задания лежат в папке **`tasks/`** (начиная с `tasks/00-BACKLOG.md`).
