# Первая проверка курса

Два этапа: взрослая репетиция проверяет продуктовый маршрут; небольшая целевая группа A2–B1 10–14 лет проверяет язык/время/самостоятельность. До набора владелец выбирает число участников/устройства/бюджет и получает необходимые разрешения. Это открытые организационные решения, не уже выполненный пилот.

У каждого псевдоним и доступ преподавателя. Таблица соответствия настоящих имён хранится отдельно. Classroom Agreement — учебное обещание, не замена разрешениям родителей/центра. Внешний AI получает текст промпта: перед вводом напомнить цифровую маску. Не собирать реальные фото лиц. Перед публикацией учитель проверяет содержание и согласованный способ передачи. Срок хранения и удаление выбрать до группы; предполагается ограниченный пилот, не бесконечное хранение.

Для каждого наблюдения: версия кода/курса, урок/поле/шаг, минуты, попытки/отказы, причина затруднения, помощь преподавателя, понял ли свои слова, объяснил ли одну содержательную правку, ожидаемое/фактическое поведение, приоритет. Использовать GitHub pilot issue без личных данных или таблицу work/pilot-notes.csv вне Git.

Успех: работа не потеряна, нет технического тупика, основной маршрут помещается в план, ученик объясняет одно улучшение. Формальное прохождение гейтов не доказывает обучение. При отказе сети — сохранить ввод, перейти к готовому учебному примеру/бумажному анализу, не выдавать demo за новую генерацию. После занятия — 2–3 важных изменения, после курса — пересмотр D03/D05/D08 по наблюдениям.
