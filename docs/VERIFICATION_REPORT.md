## Выполнено

- Исправлены экспорт четырёх AI-текстов, синтаксис анимации, безопасная вставка текста/заголовка и JSON.

- Добавлены fixtures, тесты, CI, Docker/VPS-runbook, процесс нового урока и план наблюдений пилота. Supabase, универсальный конструктор и ИИ-тьютор отложены по принятому плану.
