# Карта контекста

| Задача | Читать после базового входа |
|---|---|
| Оформление/текст кнопки | соответствующий UI и стили; смысл подсказок |
| Гейты/лимиты | Lesson_N, DECISIONS, config, validate, server, оба UI, tests |
| Генерация | ai-provider, CONTRACT, DECISIONS, API_SOURCE, tests |
| Экспорт | CONTRACT, site-builder, fill-slots, шаблон, тест результата |
| Данные/запуск | storage, settings, DEPLOY_RUNBOOK, tests/backup |
| Новый урок | ADD_LESSON, карта L1–L5, версия данных, prerequisites и рубрика |

Расширять чтение при неизвестной причине, межурочном эффекте или конфликте. SOURCES ведёт к четырём локальным обзорам; читать только нужные разделы. Архив — по необходимости установления истории, а не при каждом запуске.
