# Правила текущей версии pilot-1

Защитные принципы: ученик отвечает за итог; не теряем сохранённую работу; ключи только на сервере; реальные лица/имена не отправляем генератору; итог публикует преподаватель. Operator Rule — формулировка курса, атрибуция MOE не подтверждена первоисточником; см. curriculum/SOURCES.md.

| Урок | Принятое поведение |
|---|---|
| L1 | Бумажные карточки, псевдоним, соглашение, mind map. Учитель хранит бумагу; может поставить необязательную отметку L1 в консоли. Она не блокирует L2. Технический профиль начинает с L2; загрузчик фото не реализован и не требуется пилоту. |
| L2 | About Me: 2 промпта с оценками good/needsChange, затем ручная правка. V1 ≥5 слов, V2 +3 слова, 2 слова банка только About Me; хобби: 1 промпт, publish или ручной bonus с reason. Present Perfect в промпте/финале всех AI-текстов; About Me ≥40 слов/≤600 символов, hobby ≥15/≤200. Изменение 1 символа — технический минимум, качество оценивает учитель. |
| L3 | Аватар/фон: 3…6 оценённых версий, pros/cons ≥3 слов, менять ≥1 поля Subject/Style/Framing/Lighting, выбрать разные best/worst с причинами. Worst означает менее подходящий; ошибка модели не обязательна. |
| L4 | Три картинки: 1…6 версий, регенерация с причиной ≥3 слов и изменённым полем; можно публиковать существующую версию. Тема: RCTF, два варианта, выбор и comparative-обоснование ≥3 слов/10 символов + design word. Все шесть тем доступны: warm/calm/natural/bold/energetic/mysterious. Синонимы заданы одним конфигом. |
| L5 | Аудит двух пунктов, шесть рефлексий ≥15 слов/≤400 символов; суммарно ≥1 publish/export/change/presentation. Учитель публикует только после L2–L5. Build требует L2–L4. Исправления точечные, прежний журнал сохраняется, старые preview/publication отзываются до пересборки. |

Числа — принятые настройки pilot-1, не неприкосновенные научные константы. Их обоснование, ограничения и условия пересмотра в curriculum/DECISIONS.md. При смене правил сохранять совместимость начатых групп.

Impact Check: config → validate → server → app → teacher → template/export; затем прогресс/версия, тесты и развёртывание. Проверять все затронутые слои, не переписывать все файлы без причины. Педагогические изменения синхронизировать с Lesson Spec/DECISIONS.

AI: live не подменяется mock при ошибке; не ухудшать личный V1 специально. Подготовленный плохой пример показывать отдельно. Ответ постпроверяется; максимум один repair-повтор, затем понятный отказ. Не придумывать личные факты. Для аватара PNG с прозрачностью; тёмный фон не заменяет alpha. ИИ-тьютор отложен.
