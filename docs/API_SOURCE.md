Проверено по официальной документации 29.10.2026: https://developers.openai.com/api/docs/guides/image-generation и https://developers.openai.com/api/docs/deprecations . Текст: Responses API, модель настраивается (по умолчанию gpt-6-luna). Изображения: /v1/images/generations, gpt-image-2.5-sunburst, b64_json, PNG. Смена модели требует проверки разрешённых параметров, доступа аккаунта, лимитов и тестовых ответов. DALL-E 3 и gpt-image-1 не используются.

Live-проверки аккаунта, оплаты и детского содержимого пока NOT_RUN: ключ не предоставлен. Mock и контрактные тесты не заменяют их. Два текстовых запроса максимум на одну принятую попытку (основной + repair); изображение автоматически не повторяется. Жёсткие счётчики резервируют попытки провайдера, включая ошибки, чтобы ограничить неопределённые расходы; это не денежная оценка. Один AI-адаптер не гарантирует семантическую безопасность: до группы преподаватель проверяет контрольный набор заданий и политику провайдера.
