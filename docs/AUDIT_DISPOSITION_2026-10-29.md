Дополнительно из сравнительного отчёта: возвращена компактная карта шести слоёв/машин состояния в PLATFORM; ENV PIN нормализуется для PILOT-A → TEACHER_PIN_PILOT_A; compose PORT сопоставлен с фактическим PORT; не повторяем первоначальную миграцию; видимость репозитория остаётся решением владельца. Предложение убрать независимую приёмку не принято: локальные правила требуют её перед merge. Новую четырёхступенчатую серию PR не создаём из одного связного исправления аудита.

Методика, число попыток, возраст/уровень, config и Lesson Spec не менялись. L1 отметка необязательна. Изменены сервер, UI, служебные команды, тесты и документация; экспорт продолжает использовать тот же Node builder и контракт. Старые учебные данные не мигрированы/не сброшены.

Реальные платные вызовы не выполнялись; VPS и целевое устройство пока NOT_RUN. Для первой группы остаются только конкретные шаги BACKLOG, не полный повтор разработки платформы.
