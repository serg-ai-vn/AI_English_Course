## Проект

Платформа персональных сайтов учеников детского курса English+AI (10-14 лет, Вьетнам).
Ученик наполняет управляемый шаблон своим контентом (тексты, AI-картинки, тема), учитель контролирует результат, семья получает сайт одним HTML-файлом.
Горизонт: MVP ~1 месяц, через ~2 месяца - оттестированная платформа для продажи демо-групп английским центрам.

## Жёсткие решения (менять только с Сергеем)

- Стек: vanilla HTML/CSS/JS. БЕЗ Vite, Three.js, GSAP, Lenis.
- Particle Assemble: Canvas 2D, односторонняя сборка аватара (~1900 мс, стоп), JSON частиц считается заранее (`tools/sample-particles.ps1`), бюджеты 700/1400/3000 по железу, CSS blur+scale fallback.
- Экспорт: один самодостаточный HTML (картинки в base64, работает по file://) через `tools/export-site.ps1`.
- Дизайн: токены Dala, Preset v3 (палитра + ambient-мотив + язык форм на каждую из 6 тем).
- Контент: только AI-аватары учеников (личные фото запрещены); ровно 3 хобби; картинки: L3 = аватар+фон, L4 = хобби+тема (вариант A).
- Фоны: тематические фото под историю ученика, БЕЗ людей, текста, водяных знаков; атмосферные, не отвлекающие (сверху scrim из токенов темы).
- Этот проект независим: стилевые правила TG-канала (em-dash и т.п.) сюда не распространяются.
