## Зафиксированные решения плана

1. Активное задание хранится в [tasks/TASK-06-platform-ui-themes.md](../../tasks/TASK-06-platform-ui-themes.md); ссылка добавляется в BACKLOG и SESSION. История объясняет происхождение и границы задания.
2. Classroom Light — новый default; Night Lab остаётся действующей темой. Общая разметка/логика, семантические токены, отдельный UI theme bootstrap и preference без изменения данных урока.
3. Видимый переключатель отложен, но рабочий возврат к Night Lab обязателен уже в первом выпуске.
4. Новый статический JS требует точного разрешения в server.js; это допустимое техническое изменение без изменения API.
5. Проверки охватывают обе темы, данные, сохранение черновиков, коррекции, гейты, L4-пресеты и экспорт. Скриншоты/браузерный прогон обязательны при реализации.
6. Публикация — через draft PR, независимую приёмку конкретного SHA и согласованный выпуск. Финальная синхронизация проверяется по коммиту, дереву и чистоте tracked-рабочей копии; локальные исключённые данные не загружаются.
