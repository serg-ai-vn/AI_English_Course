# Один VPS: запуск, обновление, восстановление

Локально: Node 24 → npm ci → npm run seed → npm run build → npm run check → npm test → npm start. Demo без .env запускается на 127.0.0.1:3000. Скопировать .env.example в .env для настроек; live ключ не печатать.

VPS ещё не выбран и не развёрнут. Подготовлен Dockerfile + compose.yaml: один процесс Node 24, именованный volume /data, порт приложения доступен только с localhost VPS. На VPS установить Docker, создать .env с APP_MODE=pilot, AI_PROVIDER=openai, рабочими ключами/лимитами и TEACHER_PIN_CLASSCODE. Перед первым pilot-запуском положить в /data/classes.json непубличный класс по схеме fixtures, уникальные id и новые PIN; DEMO/0000 запрещены. Соответствие реальных имён держать отдельно.

Запуск: docker compose up -d --build. HTTPS — reverse proxy VPS (например Caddy) к 127.0.0.1:3000, домен выбирает владелец. Пример Caddyfile: YOUR_DOMAIN { reverse_proxy 127.0.0.1:3000 }. Демонстрационный режим не выкладывать в интернет как pilot.

Перед обновлением остановить приложение и сделать согласованный snapshot всех данных командой tools/backup.js backup ABSOLUTE_NEW_DIRECTORY при DATA_DIR, указывающем на volume. Для контейнера использовать копию каталога /data при остановленном app. Снимки вне Git, с ограниченным доступом. Sessions в backup не входят.

Восстановление: при остановленном приложении задать новый пустой DATA_DIR и node tools/backup.js restore ABSOLUTE_SNAPSHOT. Сверяются SHA-256; непустое назначение отвергается. Запустить эту копию и проверить вход/прогресс/изображения/сайт. Старые данные не удалять до проверки.

Откат кода: выбрать проверенный предыдущий tag/образ и совместимую courseVersion/schemaVersion. При несовместимости восстановить связанный snapshot в новый volume, не делать checkout в работающем каталоге с последующей потерей данных. Измерить время восстановления на VPS до первой группы.

Обязательная VPS-приёмка: HTTPS; известные demo-доступы отвергаются; private preview закрыт; PORT=4000 и health; пересоздание контейнера сохраняет работу/частицы; восстановление в чистой среде; полный UI-маршрут на целевом устройстве; выдача семье. Пока сервера нет, эти проверки NOT_RUN.
